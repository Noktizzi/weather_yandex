# Мониторинг погоды в РФ 🌤

Учебный прототип по ТЗ. Node.js-прокси + SPA-клиент.

## Быстрый старт

```bash
# 1. Установить зависимости
cd weather-app
npm install

# 2. Задать API-ключ Яндекс Погоды
export YANDEX_WEATHER_KEY=ваш_ключ_здесь   # Linux/macOS
set YANDEX_WEATHER_KEY=ваш_ключ_здесь       # Windows cmd

# 3. Запустить сервер
npm start
# → http://localhost:3000
```

## Переменные окружения

| Переменная            | Описание                       | По умолчанию |
|-----------------------|--------------------------------|--------------|
| `YANDEX_WEATHER_KEY`  | Ключ API Яндекс Погоды         | (обязателен) |
| `PORT`                | Порт HTTP-сервера              | `3000`       |

## API-маршруты сервера

| Метод | Путь               | Описание                          |
|-------|--------------------|-----------------------------------|
| GET   | `/api/suggest?q=`  | Автодополнение городов            |
| GET   | `/api/geocode?city=`| Координаты по названию города    |
| GET   | `/api/weather?lat=&lon=` | Текущая погода (кэш 10 мин) |
| GET   | `/api/forecast?lat=&lon=`| Прогноз 3 дня (кэш 30 мин)  |

## Деплой на Heroku

```bash
heroku create my-weather-rf
heroku config:set YANDEX_WEATHER_KEY=ваш_ключ
git push heroku main
```

## Деплой на Vercel / Railway

Задайте переменную `YANDEX_WEATHER_KEY` в настройках проекта.

## Функциональность

- ✅ Поиск с автодополнением (50 крупнейших городов РФ)
- ✅ Текущая погода: температура, ощущаемая, иконка, влажность, ветер
- ✅ Прогноз на 3 дня: дневная/ночная температура, иконка, осадки
- ✅ Избранное (до 10 городов, хранится в localStorage)
- ✅ Переключение °C / °F
- ✅ Последний город сохраняется между сессиями (localStorage)
- ✅ Кэш в памяти (текущая погода 10 мин, прогноз 30 мин)
- ✅ Ключ API — только на сервере, клиент его не видит
- ✅ Адаптивный дизайн (мобильные + десктоп)
- ✅ Обработка ошибок (неверный город, недоступность API)
