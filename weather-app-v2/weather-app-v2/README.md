# Документация проекта "Мониторинг погоды в РФ"

Эта папка содержит техническое задание и отчёт о выполненной работе для проекта веб-приложения мониторинга погоды.

## Содержимое

- **task.md** — Техническое задание (ТЗ) на разработку приложения
- **report.md** — Отчёт о выполненной работе для заказчика

## Конвертация в DOCX

Файлы созданы в формате Markdown (.md) для удобства редактирования. Для конвертации в формат DOCX используйте один из следующих способов:

### Способ 1: Pandoc (рекомендуется)

Установите Pandoc: https://pandoc.org/installing.html

Затем выполните команды:

```bash
# Конвертация технического задания
pandoc task.md -o task.docx

# Конвертация отчёта
pandoc report.md -o report.docx
```

Для улучшенного форматирования с использованием шаблона:

```bash
pandoc task.md -o task.docx --reference-doc=template.docx
pandoc report.md -o report.docx --reference-doc=template.docx
```

### Способ 2: Онлайн-конвертеры

Используйте онлайн-сервисы:
- https://cloudconvert.com/md-to-docx
- https://convertio.co/ru/md-docx/
- https://www.zamzar.com/convert/md-to-docx/

Просто загрузите файлы .md и скачайте результат в формате .docx

### Способ 3: Microsoft Word / Google Docs

1. Откройте файл .md в текстовом редакторе
2. Скопируйте содержимое
3. Вставьте в Word/Google Docs
4. Примените форматирование (заголовки, таблицы, списки)
5. Сохраните как .docx

### Способ 4: Visual Studio Code

Если у вас установлен VS Code:

1. Установите расширение "Markdown PDF" или "Markdown All in One"
2. Откройте файл .md
3. Используйте команду "Markdown: Export to DOCX"

## Редактирование

Файлы в формате Markdown легко редактируются в любом текстовом редакторе. Рекомендуемые редакторы:
